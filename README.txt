## 📌 About the Project

Real-world problems rarely reach the people best placed to solve them. Universities have talent and research capacity, industry has resources and mentorship, and communities have the problems. **Samadhan** (Hindi for *solution*) brings them together on a single platform.

> **Note:** This repository contains a **front-end concept prototype** built for SIH 2026. Challenges shown on the page are sample data, and the platform stats are illustrative demo values. There is no backend or database yet.

### The Problem
- Societal challenges are scattered, with no single place to post and track them.
- Universities have limited access to real-world problems for student projects and research.
- Industry lacks an easy channel to reach students, researchers and fresh ideas.

### Our Solution
One portal where challenges are crowdsourced, matched with the right teams and mentors, and followed from problem to impact.

---

## 🔄 How It Works

| Step | What happens |
|------|--------------|
| **01 · Post** | Organizations and communities submit a clearly defined challenge with context and expected outcomes. |
| **02 · Match** | Universities, students and experts discover challenges by skills, location, domain and interest. |
| **03 · Collaborate** | Teams work with mentors, milestones, discussions and shared resources. |
| **04 · Impact** | Solutions are piloted with partners, measured with impact metrics and prepared to scale. |

---

## ✨ Features (in this prototype)

- 🏠 **Landing page** with hero section, live-stats cards and a challenge-feed preview
- 🔍 **Challenge discovery** with live search by title, description or organization
- 🗂️ **Domain filter:** Environment, Healthcare, Education, Smart Cities, Agriculture
- 🏷️ **Status filter:** All, Open, Mentoring, Solving
- 📝 **Post a Challenge** modal form: new challenges appear instantly at the top of the feed
- 🤝 **Join team and View details** actions with toast notifications
- 🧭 **"How it works"** workflow and a **stakeholder** section (Universities, Industry, Communities, Researchers, Student Teams, Government)
- 📱 **Fully responsive** layout for desktop, tablet and mobile
- 🎨 Clean, modern UI with a sticky navbar and smooth scrolling

## 🚀 Getting Started

No installation or build step needed.

### Run locally

```bash
git clone https://github.com/SudhashuXAI/-SAMADHAN-.git
cd ./-SAMADHAN-
```

Then simply **double-click `SAMADHAN.html`** to open it in your browser.

### Deploy on GitHub Pages (optional)

1. Rename `SAMADHAN.html` to `index.html`
2. Go to **Settings → Pages**
3. Set the source to the `main` branch and save

---

## ⚠️ Current Limitations

- Data lives only in the browser's memory, so posted challenges are lost on refresh.
- There is no user login, backend or database.
- "Join team" and "View details" are demo interactions only.
